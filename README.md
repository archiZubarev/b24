# b24

Ключи Битрикс24 в хранилище системы и скилл для Claude Code, который умеет
работать с порталом через REST.

- **Ключи не лежат в файлах.** Ссылка входящего вебхука — пароль к порталу.
  `b24` держит её в Связке ключей (macOS) или Диспетчере учётных данных
  (Windows) и отдаёт наружу только человеку в терминале (`b24 copy`).
- **Claude не видит ключей.** Он вызывает портал через MCP-сервер `b24` или
  команду `b24 call`; методы чтения и записи — разные инструменты, запись
  Claude Code каждый раз показывает человеку.
- **Скилл `bitrix24`** — как настроить доступ у нового человека, какие права
  дать вебхуку, как работать с REST без граблей: лимиты, страницы, пачки,
  часовые пояса, ошибки, проверенные рецепты.
- **Документация методов** — официальный MCP `b24-dev-mcp`, подключается сам.

## Установка

macOS:

```bash
curl -fsSL https://raw.githubusercontent.com/archiZubarev/b24/main/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/archiZubarev/b24/main/install.ps1 | iex
```

Установщик проверяет контрольные суммы, кладёт программу и скилл и подключает
MCP-серверы к Claude Code (`b24 setup`).

## Первый ключ

1. В Битриксе: **Приложения → Разработчикам → Готовые сценарии → Другое →
   Входящий вебхук**. Отметьте только нужные права (для CRM с чатами —
   `crm, user, im, disk`), сохраните, скопируйте «Вебхук для вызова rest api».
2. В терминале: `b24 add work --clipboard` — ссылка уйдёт в хранилище, буфер
   очистится. Или `b24 add work` и вставить ссылку (на экране не появится).
3. Новый разговор с Claude: «покажи сделки на стадии … за октябрь».

## Команды

```text
b24 add <имя> [--clipboard]       сохранить ключ (проверяет его на портале)
b24 import <имя> --file <путь>    перенести ключ из файла
b24 list | check | default | rename | remove
b24 copy <имя>                    ссылка в буфер на 30 с, только в терминале
b24 call <метод> [ключ=значение ...] [--json …] [--all]
b24 batch имя=метод?параметры ...
b24 setup | status | mcp | version
```

Полный справочник — `skill/bitrix24/references/cli.md`.

## Разработка

```bash
go test ./...                                  # без записи в хранилище
B24_KEYSTORE_TEST=1 go test ./internal/secret  # запись b24-test в хранилище и удаление
go build -o b24 ./cmd/b24
```

Отдельный набор ключей для проверок: `B24_HOME=/tmp/b24 B24_KEYCHAIN_SERVICE=b24-test b24 …`.

Выпуск — тег `vX.Y.Z`: GitHub Actions гоняет тесты на Windows и macOS,
собирает программу для macOS (универсальная) и Windows (amd64, arm64),
упаковывает скилл и публикует выпуск с `checksums.txt`.
